# Screenshots

Images shown in the main README. They were taken with sample data.

To use your own, take a screenshot and save it here with the **same file name** to replace one,
then push. The main README picks it up automatically.

Tips:
- Use a browser window about 1440 x 900 for desktop shots so they all match.
- Don't include real customer phone numbers, bank account numbers or passwords in screenshots.
